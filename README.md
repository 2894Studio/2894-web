# 2894_ Studio — Web

Web de alto impacto y responsive de 2894_ Studio (AI + UX para equipos de diseño).
Next.js 16 · TypeScript · Tailwind v4 · shadcn/ui · React Bits (SplitText) · sistema de diseño A-Z (DM Sans, cobalto/cloud).

## Desarrollo
```bash
npm install
npm run dev      # http://localhost:3000
npm run build && npm run lint
```

- Contenido (textos, proyectos, clientes) en `src/content/site.ts`; lo marcado TODO es placeholder (lorem ipsum + imágenes de stock).
- Showreel: define `NEXT_PUBLIC_SHOWREEL_URL` con la URL del MP4.
- Plan completo: `docs/plan.md`.
